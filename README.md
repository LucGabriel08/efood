# EFOOD

O **EFOOD** é uma aplicação web de delivery desenvolvida em **React** e **TypeScript**, permitindo que o usuário navegue por restaurantes, visualize o cardápio, adicione pratos ao carrinho e finalize pedidos através de um fluxo completo de checkout integrado a uma API.

## 🚀 Tecnologias utilizadas

* React
* TypeScript
* Redux Toolkit
* RTK Query
* React Router DOM
* Styled Components
* React Input Mask
* Formik
* Yup

## ✨ Funcionalidades

* Listagem de restaurantes
* Página de detalhes do restaurante
* Visualização do cardápio
* Modal com informações do prato
* Adição e remoção de produtos no carrinho
* Carrinho lateral
* Fluxo de checkout

  * Entrega
  * Pagamento
  * Confirmação do pedido
* Integração com API para envio de pedidos
* Exibição do número do pedido após a compra
* Layout responsivo

## ▶️ Como executar o projeto

Clone o repositório:

```bash
git clone <URL_DO_REPOSITORIO>
```

Entre na pasta do projeto:

```bash
cd efood
```

Instale as dependências:

```bash
npm install
```

Execute a aplicação:

```bash
npm start
```

O projeto será iniciado em:

```text
http://localhost:3000
```
